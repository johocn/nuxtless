(2) 多租户支付交集 —— 全局支付区三态

已选箱白名单 → 求交集 → 判定合并/分箱
盒A(J店·物流) 白名单 { 微信, 支付宝 }
盒B(顺丰·物流) 白名单 { 支付宝, 货到付款 }
盒C(门店·自提) 白名单 { 货到付款 }

场景① 全选 A+B+C → 交集 ∩ = 空 → 顶部红条「各箱支付方式不同，将分箱支付」→ 支付区按箱列出各自唯一方式，提交按箱拆单
场景② 只选 A+B → ∩ = { 支付宝 } 非空 → 提示「将合并 1 单，用 支付宝」→ 合并单统一收款，实收按商户分账
余额特例：选「余额」→ 钱包充足且全箱支持 → 合并 1 单共享钱包扣；不足 → 余额禁用 + 提示「余额不足，分箱支付」
规则：不放合并/分箱开关；系统按 ∩ + 余额自动判定
