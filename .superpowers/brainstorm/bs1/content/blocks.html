订单模块 · 积木结构设计（方案 A · 京东手机帮风）

绿=新建蓝=复用现有组件/逻辑　单一京东风格·代码层组件化·块内建默认·响应式

① 订单列表页 · OrderCard 积木
OrderTabBar 顶部状态TaB复用 ORDER_TABS + tabOfState，全部分状态筛选复用
OrderCard（列表卡片容器·自适应列数）新建
OrderCardHeader 卡头店铺/站内标识 + 状态徽标 stateBadge；整卡可点跳详情复用 stateBadge
OrderCardItems 商品缩略行图 + 名称 + ×N + 单价；取 OrderBase.lines新建
OrderCardFooter 合计「共N件 实付 ¥X」totalWithTax新建
OrderCardActions 操作条按状态渲染：去支付/再次购买/查看详情/取消；复用 useOrderActions(canCancel/cancelOrder/reorder)复用
OrderCardList 列表容器取 totalItems + take 做「加载更多/滚动加载」新建
② 订单详情页 · 竖排信息卡积木
OrderStatusBanner 状态横幅渐变底 + 订单状态 + 附带说明；替代当前 header 区新建
OrderStateProgress 进度条复用 OrderProgress + progressIndex复用
OrderAddressCard 收货地址卡收货人/电话/地址（含自提点联系人）复用 OrderAddress
OrderItemsCard 商品清单卡商品行 + 售后入口（canApplyAfterSales）；移动端竖排复用 OrderItems
OrderPickupCard 自提信息卡deliveryType=pickup 时显示：提货码/自提点/核销状态新建
OrderTotalsCard 金额明细卡商品/运费/优惠/实付；复用 OrderTotals+OrderShippingBreakdown复用
OrderMetaCard 订单信息卡订单号/下单时间/支付方式/配送方式新建
OrderActionsBar 底部操作条去支付/再次购买/退款/售后/确认收货；复用 OrderActions复用

数据流

  • 列表：GetOrderHistory(totalItems/skip/take) → OrderCardList 分页渲染 OrderCard
  • 详情：GetOrderByCode(OrderDetail) → 各功能卡按 state / deliveryType / canApplyAfterSales / canCancel 条件取块显隐
  • 操作动作统一走 useOrderActions（取消/再次购买/去支付）+ 售后 Modal；成功后 refresh()
  • 响应式：列表卡片 grid-cols-1 → md:grid-cols-2；详情单列信息流宽度自适应
