# nshop 本地电商底座 · 实施计划（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 subagent-driven-development（推荐）或 executing-plans 按任务逐一落实。任务用 `- [ ]` 勾选跟踪。

**Goal:** 在 nshop 前端底座上落地四大块：首页运营位组件化（后台可装修）、商品展示模板、5 套渠道级配色主题、并保持共享同一 Vendure backend（默认租户、商品级配送、支付档案）。

**Architecture:**
- 后端 `operations-plugin`（vendure 单仓）扩展现有 `ContentItem`（单表多态）判别类型 `IconGrid`/`CategoryNav`，装饰者 `validateDataByType` 校验；通过插件 `configuration` 回调合并 `Product.customFields.displayTemplate` 与 `Channel.customFields.themeId`。新类型无需改 schema（type 是 String、data 是 JSON）。
- nshop 首页把 `publishedContent` 从「只认 hero/floor」升级为「type→组件」通用映射；商品详情按 `displayTemplate` 切换布局；配色用语义令牌 + `<html data-theme>`（渠道级固定，SSR 无闪烁）。
- admin「首页装修」页在既有阶段45 Dashboard 基础上做 ContentItem 列表/编辑/排序。

**Tech Stack:** vendure（operations-plugin/TypeScript/admin Angular）、nshop（Nuxt 4 + nuxt-graphql-client + @nuxt/ui 4 + Tailwind 4 + Pinia）、GraphQL。

```ts
// layers/base/app/utils/home-content-block.ts
export type ContentBlockType = 'Banner' | 'Recommendation' | 'Notice' | 'Floor' | 'IconGrid' | 'CategoryNav';

export interface ContentBlock {
    id: string;
    type: ContentBlockType;
    name: string;
    sort: number;
    data: any;
}

export function resolveBlockKind(item: { type: string; data?: any }): ContentBlockType {
    const t: string = item.type ?? '';
    if (['Banner', 'Recommendation', 'Notice', 'Floor', 'IconGrid', 'CategoryNav'].includes(t)) {
        return t as ContentBlockType;
    }
    return 'Floor'; // 未知类型兜底，仍有序渲染
}
```

```ts
// layers/base/app/composables/useChannelTheme.ts
export function useChannelTheme() {
  const config = useState<string>('channel-theme', () => 'default');

  async function loadTheme() {
    const res = await useAsyncGql('GetChannelTheme', {}, { server: true });
    const id = res.data.value?.activeChannel?.customFields?.themeId ?? 'default';
    config.value = id;
    return id;
  }

  function applyTheme() {
    if (import.meta.server) return; // SSR: 由 layout/useHead 同步
    document.documentElement.setAttribute('data-theme', config.value);
  }

  return { config, loadTheme, applyTheme };
}
```
