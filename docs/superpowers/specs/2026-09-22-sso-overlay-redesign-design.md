# SSO 等待遮罩动效焕新 + 排版上移设计（星轨卫星环 · 星枢关系中心）

日期：2026-09-22
状态：待评审
仓库：nshop（www.youshop.cn）
文件：`layers/base/app/components/SsoAwaitOverlay.vue`

## 1. 背景

上一轮上线了微信端 SSO 自动登录的品牌化等待遮罩（`SsoAwaitOverlay.vue`），动效为居中圆环 spinner、标题「星枢统一关系中心」、4 条广告语轮播、状态文案「正在校验登录凭证…」。

用户反馈希望在新一轮精修：**动效更现代、放大、位置上移到醒目区；标题精简；替换「登录中」类状态文案**。本轮为对本组件一次纯视觉焕新（不动登录链路逻辑）。

## 2. 视觉方案（已与用户确认）

### 2.1 动效 → 星轨卫星环
- 用**品牌紫发光核心球 + 半透明虚线轨道环 + 环绕卫星点**替代原纯圆环 spinner。
- 核心球：径向渐变（亮部 `#a5b4fc` → 主紫 `#667eea`），带发散光晕（`box-shadow`）。
- 轨道环：`2px dashed rgba(102,126,234,.35)` 圆环。
- 卫星点：纯白小圆（`box-shadow` 品牌紫辉光），沿轨道以 `transform-origin` 绕转（约 1.6s linear 一周）。
- 视觉重心放大：轨道整体 `~96px`（原 spinner 52px），成为遮罩视觉主元素。

### 2.2 排版 → 上移居中（方案 1）
- 遮罩内容垂直布局，视觉重心上移到**中上部醒目区**，不顶死（`justify-content: center` 并配合 `padding-top` 略上移）。
- 内容自上而下：**动画（放大）→ 标题 → 广告语（轮播）→ 状态胶囊**，间距收紧。

### 2.3 文案
- **标题**：精简为「**星枢关系中心**」（去掉「统一」），字号可略放大、更醒目。
- **状态文案**：由「正在校验登录凭证…」替换为「**星枢正在为您护航…**」（品牌人格化、带温度）。
- **广告语**：保留现有 4 条轮播（同现状），每条 2.6s 淡入切换：
  1. 一个账号，玩转全部系统
  2. 星枢，让系统彼此相连
  3. 登录一次，处处同步
  4. 安全 · 统一 · 更便捷

### 2.4 品牌与无障碍
- 保持品牌紫 `#667eea` 主色、淡背景（`#f5f5f7` 或类近渐变）。
- `prefers-reduced-motion: reduce` 下降级为静态（关闭卫星旋转与广告语轮播，其余静置）。

## 3. 交互与降级约束（沿用现逻辑，不重做）

- 触发条件不变：客户端 + 微信浏览器 + 未登录 + 非跳过页 + 进入自动登录流程（`pending` 置真）。
- 预取/跳转链路（`useSso.startProviderPrefetch` / `getRedirectProvider`、`useAutoWechatSsoLogin`、`shouldShowOverlay`）**不改**，本 spec 只改视觉组件。
- 无 provider 时返回 `getPendingState().value=false` 关闭遮罩，逻辑不变。

## 4. 非目标

- 不改登录链路、预取/跳转逻辑、触发条件。
- 不改 h.joho.cn 星枢登录页门面（strapi 侧）。
- 不做多仓库运行时共享字典。
