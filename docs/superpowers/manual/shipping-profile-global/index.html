一、背景与后端权限缺口

需求

配送档案此前仅归属于单个租户（isGlobal=false，仅该租户可见）。业务需要一种「全局档案」：由超级管理员维护、全平台各租户可选用（列表共性可见），用于平台级统一配送规则（如「门店自提配送档案」全渠道复用）。

后端权限缺口（本次补齐）

  • create：超管新增档案可带 isGlobal:true；assertProfileGlobalPermissions(ctx,'create',…) 校验——仅超级管理员可创建全局档案，非超管传 isGlobal:true 直接拒绝。
  • update：超管切换 isGlobal 时维护 ownerChannelId（全局→null，转租户→当前渠道）与 isTenantDefault（开全局自动清「租户默认」）；非超管不能改动全局档案、也不能改全局属性。
  • delete：非超管不能删除全局档案（仅超级管理员可删除全局档案）。
  • 列表 findAll：WHERE (sp.isGlobal = true OR sp.ownerChannelId = :channelId) —— 全局档案对每个租户都可见。
// shipping-profile.service.ts —— 全局属性一致性维护（关键分支） if (input.isGlobal === true) { ... profile.ownerChannelId = null; profile.isGlobal = true; } else if (input.isGlobal === false) { ... profile.ownerChannelId = ctx.channelId; profile.isGlobal = false; }

二、功能说明

2.1 超管「设为全局」开关（新建 / 编辑）

配送档案表单中，仅超级管理员看到「设为全局」开关（非超管不渲染）。新建时默认关，点开弹出确认「开启后所有租户可见，确认？」；确认后：开关开、ownerChannelId 置 null，且「设为租户默认」置灰、hint 显示「全局档案不可设为租户默认」——全局档案与租户默认互斥。编辑全局档案时开关为开、hint 显示「全局档案对所有租户可见，仅超管可维护」；超管可再切回关（此时归属当前渠道、允许设租户默认）。

2.2 列表「全局」徽标

配送档案列表卡片，全局档案名称旁显示全局（global-badge，紫色 #7c5cfc）。

2.3 非超管只读（UI + 后端双重）

  • UI 只读：非超管视角下，全局档案卡片操作区替换为「仅超管可维护 · 不可编辑」，无编辑 / 删除 / 启停开关；进入编辑态时钟展示「设为全局」只读禁用开关（hint「全局档案 · 仅超管可维护」）。本租户自有（非全局）档案操作正常。
  • 后端校验：即便绕过前端，非超管调 update / delete 也会被拒（create 带 isGlobal:true 亦拒）。
上线权限说明（重要） 后端权限策略要求档案类操作需 ShippingProfile 权限。当前线上默认租户管理员角色（t2-tenant-admin / official-tenant-admin-N 等）均未包含该权限，因此非超管默认连「配送档案列表」都进不去（返回 FORBIDDEN → 空列表）。本手册的「非超管只读」截图使用临时测试角色（默认渠道，克隆租户管理员权限并追加 ShippingProfile）来演示该只读 UI；生产若要对各租户管理员开放只读查看，需在其角色上补授 ShippingProfile 权限（详见第四节）。即使补授后，非超管仍无法对全局档案做任何维护（受后端 create/update/delete 三层校验拦截）。

四、已知问题

description 列 NOT NULL 但 GraphQL schema 可选

  • 线上库 shipping_profile.description 为 NOT NULL，但 GraphQL 的 CreateShippingProfileInput.description 为可选；若 API 层不传 description，undefined 会触发数据库 NOT NULL 报错。
  • 前端表单始终显式传 description（无内容时传空串 ""），传空串不受影响，故 UI 使用正常。
  • 建议后续将列改为可空或加默认值，使 API 层缺省不报错。

租户只读视角需补授权限

线上默认租户管理员角色普遍未带 ShippingProfile 权限，非超管默认进不了档案列表。若希望各租户管理员「可看全局档案、不可维护」，需在其角色上补授 ShippingProfile 权限——此为本次「非超管只读」的投产前提，待平台角色策略统一后生效。
