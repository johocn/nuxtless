一、方案概述

微信内置浏览器未登录进入商城时，会自动跳转 h.joho.cn 统一登录页完成 SSO 静默授权。原实现在跳转前需实时网络拉取 SSO provider，出现白屏等待。本方案三项改造（登录链路未动，预取/跳转逻辑保持 Task1 既有）：

  • 提速（预取优先）：useSso.startProviderPrefetch() 在 app.vue setup 即幂等预取 provider（localStorage 10 分钟 TTL 缓存）；跳转时 getRedirectProvider() 预取命中 → 省略二次网络，立即跳转。
  • 等待区品牌化：跳转发起前置 pending=true，未登录 + 微信环境渲染品牌遮罩 <SsoAwaitOverlay />（星枢紫 #667eea），替代原白屏。
  • 动效焕新（Task1）：遮罩主视觉升级为放大星轨卫星环div.sso-orb 三件套——品牌紫发光球（core）、虚线轨道环（ring）、白点卫星环绕（sat，1.6s 匀速公转）；整体居中上移排版；标题精简为「星枢关系中心」；状态胶囊「星枢正在为您护航…」；4 条广告语轮播（2.6s 淡入切换）；prefers-reduced-motion 时关闭旋转/轮播动画，仅静态品牌卡。

二、关键路径与降级

场景行为
预取命中（缓存/lazily 已就绪）直接复用预取 provider，遮罩几乎不闪，立即跳 h.joho.cn
预取未命中（等待期）pending=true → 品牌遮罩兜底，同时实时拉取补齐
无 providerpending=false，不跳转、不遮罩，停留当前页
非微信 / 已登录 / 跳过页不触发自动登录，shouldShowOverlay 恒 false，遮罩不出现
prefers-reduced-motion关闭旋转/轮播/淡入动画，仅静态品牌卡（可访问性降级）

五、验收指引

  1. 微信内首次访问首页（未登录）→ 应出现星枢品牌等待遮罩或立即跳转统一登录页，避免白屏。
  2. 二次触发（provider 已缓存/预取）→ 遮罩几乎不闪，直接跳转（提速生效）。
  3. 桌面 / 普通移动浏览器访问 → 无跳转、无遮罩，正常浏览。
  4. 系统开启「减少动态效果」→ 遮罩只静态展示，不含旋转/轮播动画。
