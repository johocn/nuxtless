已部署 nshop 前端，生产 www.youshop.cn 于 2026-09-11。

一、功能说明

在微信内置浏览器中访问商城首页且未登录时，自动发起 SSO 微信静默授权登录：自动跳转 h.joho.cn 统一登录页 → 微信授权 → 回跳首页并携带 token → 用 accessToken 直验换 Vendure 会话，登录完成后停留在首页。无需手动点「登录」。

  • 仅触发条件：客户端 + 微信内置浏览器（UA 含 MicroMessenger）+ 当前未登录。
  • 已登录、非微信、或桌面浏览器访问首页：不做任何自动跳转，正常浏览。
  • 一次会话只自动跳一次（youshop_sso_auto_jumped），避免循环打断浏览；拉取提供商失败/超时时会清除该标记并撤掉遮罩，停在首页可正常浏览，同一会话再次进入仍会重新尝试（见第八节）。

二、实现链路

useAutoWechatSsoLogin.ts（app/composables）在首页 app/pages/index.vue <script setup> 顶层调用。核心：isInWechatBrowser() 检测 UA → useSso.fetchProviders() 从当前渠道 shop-api ssoProviders 动态读 zhao-sso 提供商（不硬编码域名）→ loginWithSso(provider, { returnUrl: 首页 }) 跳 h.joho.cn 统一登录页。回调携带 ?token= 回跳首页后，hasPendingCallback → exchangeSsoAccessToken → authStore.setUser 完成会话建立。

提供商配置存于 Vendure Channel.customFields.authConfig → ssoProviders，前端经 ssoProviders GraphQL 字段动态读取。

六、常见问题排查

  • 微信内不自动跳转：确认提供商已配置（后台 店铺信息 → 统一登录/SSO 配置，须含 __default_channel__ 的 zhao-sso 提供项）；确认未设置 youshop_sso_auto_jumped（换会话/清缓存后重试）。
  • 回跳后未登录：检查 ?token= 回跳参数与 sessionStorage.youshop_sso_provider 是否一致；token 失效时前端静默清除状态，用户可手动走登录页。
  • 同一微信二次建档：确认 zhao-sso 后端按 openid/unionid 命中已绑定 ssoId，未命中才新建（见 SSO 微信登录逻辑）。

八、健壮性修复：接口故障时遮罩卡死 + 同会话可重试（2026-10-25 更新）

故障现象（本次线上故障期间实测）：微信内打开首页偶发长时间停在「星枢正在为您护航…」品牌遮罩，首页内容完全无法浏览，只能杀进程重进。根因是 useAutoWechatSsoLogin.run() 直接 await getRedirectProvider()，而底层 fetchProviders() 既无 try/catch 也无超时——接口 502/断网时 run() 抛错或永久挂起，pending 标志永不复位，SsoAwaitOverlay 就永久盖住首页；同时 AUTO_JUMP_KEY 在整个 session 内只允许跳一次，首次失败后同 session 不再重试。

修复（layers/base/app/composables/useAutoWechatSsoLogin.ts）：

  • run() 全程 try/catch/finally：只有确实发起了跳转才保持遮罩到页面离开，其余任何分支都在 finally 复位 pending；
  • getRedirectProvider() 外包 withTimeout(…, 10s)：网络挂起时 10 秒后放弃本轮跳转并撤罩，不再永久遮挡；
  • 拉取失败时 sessionStorage.removeItem(AUTO_JUMP_KEY)：同一会话下次进入仍会重试，等接口恢复即可自动登录；
  • 启动预取加 .catch()：失败只 console.warn，不产生 unhandledRejection，也不影响后续实时拉取。

验证方式：Playwright 手机视口（390×844，dpr=2）+ 微信 UA（MicroMessenger），用路由拦截屏蔽所有 shop-api 请求，模拟两种线上故障：fail（请求立即中断，等价 502/断网）与 hang（请求永不返回，等价网络挂起）。

场景预期实测结果
fail：接口全部中断遮罩最多短暂出现，随即撤掉，首页正常展示通过：1.2s 时即无遮罩，13.2s 后仍无；日志 [sso] 微信自动登录跳过（provider 拉取失败） + [sso] provider 预取失败，无 unhandledRejection
hang：接口永不响应遮罩出现 → 10s 超时后自动撤掉，首页可浏览通过：1.2s 遮罩在（overlay=1），13.2s 遮罩已撤（overlay=0）
同 session 二次进入（故障仍在）AUTO_JUMP_KEY 已被清除，重新尝试并重新显示遮罩，不会「一次失败即整场放弃」通过：重进页面 1.2s 时遮罩重新出现（overlay=1）
